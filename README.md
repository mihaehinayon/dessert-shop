### My Learning Process

**Background:** I come from a graphic design background and am a complete beginner in programming. This project was my first real JavaScript application.

**Learning Approach:**
1. **Conceptual Learning** (4+ hours with Claude AI)
   - Studied HTML semantic structure and CSS Grid systems
   - Learned JavaScript fundamentals: variables, functions, arrays, objects
   - Understood DOM manipulation and event handling concepts
   - Worked through step-by-step explanations with visual analogies

2. **Practical Implementation** (X hours with Claude Code)
   - Used AI assistance to implement the concepts I learned
   - Asked questions about code decisions and alternatives
   - Debugged issues while understanding the solutions

**CSS Grid Layout:**
- How `grid-template-columns: repeat(3, 1fr)` creates equal columns

- Understanding `gap` property for spacing

**JavaScript Fundamentals:**
- Difference between `const`, `let`, and variable naming
- Event handling with `addEventListener`
- DOM manipulation with `createElement` and `appendChild`
- Working with object data from JSON files

**Problem-Solving Skills:**
- Breaking down complex features into smaller functions
- Understanding the relationship between HTML structure, CSS styling, and JavaScript behavior
- Debugging by using `console.log` to track data flow
